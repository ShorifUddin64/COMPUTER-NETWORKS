## 📌 Overview
This repository contains various network design simulations created using **Cisco Packet Tracer**. It covers fundamental networking concepts, device configurations, and topology implementations.

---

## 🛠️ Included Labs / Topologies
* **LAN Configuration:** Basic Local Area Network setup using switches and routers.
* **Star Topology:** Centralized connection design using network switches.
* **Ring & Tree Topologies:** Advanced hierarchical network structuring.
* **Router & Switch Configurations:** IP addressing, routing, and connectivity tests.

---

## 🚀 How to Use
1. Download and install **Cisco Packet Tracer** on your computer.
2. Download any `.pkt` file from this repository.
3. Open the file directly using Cisco Packet Tracer to view and test the simulation.
